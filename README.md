# 📊 Dashboard de Compras

Este dashboard foi desenvolvido em **Power BI** com o objetivo de analisar e acompanhar as compras realizadas pela empresa de forma clara e interativa.

## 🔎 Principais Métricas
- **Total Comprado**  
- **Total por Fornecedor**  
- **Total por Mês**  
- **Compras por Produto**

## 🛠️ Funcionalidades
- Filtros dinâmicos por **Ano**, **Mês** e **Fornecedor**  
- Visualizações que facilitam a identificação de tendências e análise de fornecedores  
- Análise detalhada dos produtos comprados ao longo do período  

## 🚀 Objetivo
O dashboard foi construído para oferecer uma visão consolidada das compras, auxiliando na tomada de decisão e no controle de custos.
